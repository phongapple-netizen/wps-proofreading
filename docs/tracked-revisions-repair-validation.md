# 修订模式定位与批量修正验证

日期：2026-10-03。项目：`C:\Users\phong\Desktop\WPS文本校对`。

本次业务修改在 `js/proofreading-integration.js`，回归测试在 `test/proofreading-integration.test.js`。此前的面板 UI 和仅用规则校对功能保留。修复前文件备份在 `dist/tracked-repair-backup-20261003-092722/`。

## 修复内容

- 分开保存正文的逻辑长度和 WPS 原生范围终点，支持带已有修订的选区。
- 重复上下文必须通过完整作用域、文档身份和正文位置证明后才能定位；原文发生变化、副本消失或原生读取失败时拒绝写入。
- 选区使用捕获的原生终点，避免重复尾部文字导致范围过早结束。
- 写后核对修改后的正文及目标位置，防止另一段相同文字被当成本次修改的位置。
- 一键修正在原生撤销记录中从后往前写入，每条修订写入后核验；无法确认结果时停止并使旧坐标失效。
- 批量统计区分已修正、写入未确认、未尝试和人工确认项。已确认修改发生记录失败时仍计入已修正。
- 批量操作切换文档时停止，保留新文档的建议和状态。
